# 🎮 Camino de Leyendas (Versión Web)

**Camino de Leyendas** es un juego de mesa por turnos inspirado en una versión original desarrollada en **Python para consola** como proyecto académico.  
Esta versión es una adaptación **web usando HTML, CSS y JavaScript**, adaptando la lógica del juego al entorno del navegador.

Aunque mantiene la idea y mecánicas principales del juego original, esta versión puede incluir cambios, ajustes y nuevas implementaciones en la jugabilidad, la interfaz y el funcionamiento general del juego.

## 📚 Origen del proyecto

El juego nació a partir del siguiente proyecto académico:

> _El siguiente proyecto consiste en desarrollar una dinámica de juego de mesa mediante el uso del lenguaje de programación Python, empleando algunos módulos que este ofrece para poder llevar a cabo un juego interactivo con los usuarios o jugadores que se adentren en el Camino de las Leyendas._

La **versión original en consola** fue desarrollada como trabajo académico **por mí junto a dos amigos**. Sin embargo, la **versión web** surge como una **práctica personal**.

## 🎮 ¿De qué trata?

Camino de Leyendas es un juego de tablero para 2 a 4 jugadores. Cada jugador elige un personaje y avanza por un tablero de 40 casillas lanzando un dado. <br> El primero en llegar a la meta gana.
En el camino encontrarás casillas especiales que pueden ayudarte o perjudicarte.

**🛠️ Nota de desarrollo**

Este proyecto se encuentra actualmente en fase de pruebas.
Por el momento, la lógica y la modalidad del juego pueden diferir de la versión original ya que 
no todas las mecánicas y reglas del juego original han sido implementadas todavía. <br> Algunas funcionalidades pueden comportarse de forma diferente mientras se continúa migrando y adaptando la lógica del juego a esta nueva versión.
